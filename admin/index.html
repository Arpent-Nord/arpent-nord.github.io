Administration

Outils réservés à l'administration des contrats. Monday est la seule source pour les employés : cette page vérifie les données et produit le fichier de référence utilisé par la Gestion des levés.

Cette page doit être ouverte dans Chrome ou Edge sur un ordinateur.
Dossier des contrats : aucun Même dossier que la Gestion des levés (01_ACTIFS, ou 99_EN RODAGE pendant le rodage). Le fichier de référence est dans 01_TRAITEMENT\_SYSTEME\reference.json.

Créer un contrat de test

Rodage seulement : le dossier choisi doit être 99_EN RODAGE. En production, l'arborescence est créée par l'administration à la mise en route du contrat (fiche d'ouverture). Le contrat s'active ensuite dans Gestion des levés.

Codes arpenteurs

Règles : un code par personne, de 01 à 99, commun aux deux compagnies, attribué en prenant le plus petit numéro jamais utilisé; un code n'est jamais réattribué avant la fin de la période de conservation. Chaque attribution garde sa date de début et de fin : un levé est relié à l'arpenteur qui détenait le code à la date du levé.

Dans Monday : ouvrez le tableau → menu « … » → Exporter vers Excel. Faites-le pour les deux tableaux, puis choisissez les deux fichiers ici. Les colonnes lues sont Name, Numéro arpenteur (ou # arpenteur), et si elles existent Date d'attribution et Date de fin; le groupe ARCHIVE indique un employé inactif.

Natures de levé (NAT)

Code de 3 lettres utilisé dans le nom des fichiers (AAMMJJSECT#NATSS). Retirer une nature rend non conformes les levés qui l'utilisent : préférez la conserver.

Extensions des données brutes

Séparez les extensions par des virgules, ex. .dc, .job. Les fichiers .X01 à .X99 (DBX Leica) sont toujours traités comme « méthode à préciser ».

Adresses SharePoint de 01_CONTRATS

Adresse web du dossier 01_CONTRATS de chaque entité, ouverte dans le navigateur. Les modules s'en servent pour construire les liens vers les dossiers des contrats (ex. avis de validation d'implantation). Le préfixe du contrat (AN ou MA) détermine l'adresse utilisée.

Enregistré avec les tables ci-dessus (bouton « Enregistrer dans reference.json »).
