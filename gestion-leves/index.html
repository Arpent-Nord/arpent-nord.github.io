Gestion des levés

Dépôt des levés, répartition par contrat et index. Les fichiers sont écrits directement dans votre dossier OneDrive synchronisé, puis OneDrive les envoie dans SharePoint. Aucune donnée ne passe par GitHub ni par un autre serveur.

Ouvrez cette page dans Chrome ou Edge, sur un ordinateur. Ce navigateur-ci ne permet pas à la page d'écrire dans vos dossiers.

Copiez le lien, puis collez-le dans Edge (déjà installé sur tous les ordinateurs Windows) ou dans Chrome.

Pourquoi ?

La page dépose vos fichiers directement dans le dossier OneDrive de l'ordinateur, qui les synchronise ensuite avec SharePoint. Seuls Chrome et Edge, sur ordinateur, permettent à une page web d'écrire dans un dossier. Firefox, Safari et les téléphones ne le permettent pas.

Vos données ne passent jamais par GitHub : GitHub ne fait qu'héberger la page elle-même.

Boîte de dépôt – 01_TRAITEMENT

Les lots sont regroupés par contrat selon le code de secteur du nom de fichier. « Répartir » déplace le lot dans le dossier 00_LEVES_A_TRAITER du contrat et l'inscrit à l'index avec le statut « À traiter ».

Les étiquettes sont des indicateurs, pas des boutons. Les actions sont en bas de chaque lot.

Nouveau
Arrivé depuis votre dernière visite. « Marquer tout comme vu » retire l'étiquette.
Conforme
Le nom respecte AAMMJJSECT#NATSS et le secteur appartient à un contrat : le lot peut être réparti.
À vérifier
Le nom ne respecte pas la norme; la raison est indiquée sous le lot. Utilisez « Corriger le nom » : seul le fichier d'exportation (.txt et _MODIF) est renommé, les données brutes gardent leur nom de terrain. Un lot réparti sans correction reste « À vérifier » à l'index.
Documents
Lot sans fichier de levé (scans, notes, photos) : choisissez le contrat, puis répartissez.

Contrats

Activer un contrat

Le dossier du contrat et son arborescence sont créés par l'administration à la mise en route du contrat. Ici, on valide l'arborescence et on précise comment les levés du contrat sont identifiés (code SECT du nom de fichier).

Commun à tous les secteurs du contrat, complété par le secteur pour faire 4 caractères. Ex. CA + NP = CANP; D + SI1 = DSI1.
SECT (4 car.)WBS du clientDescription
Séparateurs acceptés : tabulation (Excel), virgule, point-virgule ou tiret.

Si des levés ont été faits sous un ancien code (ex. numéro de contrat changé en cours de mandat), déclarez-le ici, en tout temps : ces levés seront reconnus et leur nom corrigé sera proposé d'office. Les données brutes et les rapports gardent leur nom d'origine.

Contrat de test pour le rodage : il se crée maintenant dans l'Administration, avec son arborescence complète. On l'active ensuite ici.
